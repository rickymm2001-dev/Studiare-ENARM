# Borradores de contenido demo

Aquí se escriben los lotes de preguntas antes de unirlos a src/demo/content/questions. Cada lote va en su carpeta, por ejemplo b5, con un cases.json y dos o más part-*.json. Los borradores se suben al repositorio para que una sesión nueva pueda continuar un lote a medias.

El flujo completo está en docs/contenido-demo.md.
